## 🟢 Cos'è Deras?

**Deras** è un sistema operativo leggero e open source realizzato interamente in **DrawNote** — letteralmente, un'app per prendere appunti e disegnare.

Sì, hai letto bene: **un sistema operativo fatto in un blocco note.** 😄

### 📱 Hai DrawNote?

Se non hai ancora DrawNote, puoi installarlo dal Google Play Store:

[![Google Play](https://img.shields.io/badge/Download-Google_Play-green?logo=googleplay&logoColor=white)](https://play.google.com/store/apps/details?id=com.dragonnest.drawnote)

> [!NOTE]
> L'app di DrawNote per iOS è stata rimossa e non è più disponibile.

## 📦 Installazione

Per installare Deras, segui questi passaggi:

1. Scarica il file `.dnotesp` o `.dnotes` dalla sezione **Releases**.
2. Crea una cartella in cui vuoi installare Deras.
3. Apri DrawNote e premi il pulsante **`+`**.
4. Premi i **tre puntini `⋮`**.
5. Seleziona **"Importa dati da fonte esterna"**.

   <img src="docs/images/readme/Installation_1.jpg" width="350" alt="Menu di importazione di DrawNote">

6. Seleziona **"Importa file dati grezzi"**.
7. Seleziona il file `.dnotesp` o `.dnotes` che hai scaricato.
8. Scegli la cartella in cui vuoi installare Deras.
9. Premi **Conferma**.

Al termine dell'installazione troverai Deras nella cartella scelta.

---

## ▶️ Avviare Deras

Dopo aver installato Deras:

1. Apri la cartella di Deras.
2. Apri il file **`.main`**.
3. Premi sul **collegamento della nota gigante**.
4. Verrai portato alla **lock screen di Deras**.

🎉 **Deras è avviato!**
